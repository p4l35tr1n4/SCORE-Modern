# V commands · SCOR4

## In SCORE Modern Core

`VER` also displays the SCORE Modern version and private build number shown on the title screen.

## SCOR4 reference

> Source: Tom’s Help, edited by Thomas M. Brodhead.

*Original fixed-width diagrams and examples retain their source spacing.*

VER = SCORE version number.

This tells you the version number of the program being used. It also gives the serial number of this particular copy of the program.

If an earlier written SCORE file is on the screen, VER tells the serial number of the program that wrote the file, as well as the date it was saved.

VJ = Vertical Justify.

This command condenses the vertical spacing to the minimum possible to avoid overlaps.  The prompt asks for 3 numbers.

The 1st number sets the minimum vertical distance (in scale steps). The 2nd number sets the desired horizontal clearance. The 3rd number sets the minimum veritical distance between staves. (This is useful when some staves have only rests in them.)

Usually you will want to use the H command (set total height) after using VJ.
