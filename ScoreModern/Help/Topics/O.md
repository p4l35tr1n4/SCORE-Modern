# O commands

## SCORE reference

> Source: Tom’s Help, edited by Thomas M. Brodhead.

"OH" = reorder all items in horizontal (left-to-right) order starting on lowest staff. "OS" = reorder all items by staff number. (Left to right on each staff, from lowest to highest staff). "OT" = reorder text items only (by staff, starting with HIGHEST staff).

These are sometimes useful to simplify large-scale editing.

(Several group commands (Lineup, etc.) automatically do an "OS".)
