# Rhythm input · SCOR4

## SCOR4 reference

> Source: Tom’s Help, edited by Thomas M. Brodhead.

*Original fixed-width diagrams and examples retain their source spacing.*

The following keys are active in the Rhythms Input section of SCORE.

SCORE Command Language:

```text
       D or .5 - Enter a Double Whole note rhythm.
       W or 1  - Enter a Whole note rhythm.
       H or 2  - Enter a Half note rhythm.
       Q or 4  - Enter a Quarter note rhythm.
       E or 8  - Enter a Eighth note rhythm.
       S or 16 - Enter a Sixteenth note rhythm.
       32      - Enter a Thirty-second note rhythm.
       64      - Enter a Sixty-fourth note rhythm.
       128     - Enter a 128th note rhythm.
       20,28   - 20th note(quintuplet), 28th(septuplet), etc., etc.
       .       - Follows rhythm to make it dotted. Double dots O.K.
       T       - Precedes letter rhythm to make it a triplet.
       n1:n2   - Complex rhythm.  n1 in time of n2 quarters.
       G       - Grace note rhythm. For mini-notes with flag and slash.
       /       - Slash is used to separate the above commands.
       //      - Extra slash(es) repeat previous command.
       ;       - Semi-colon is used to end rhythm input.
       RXn     - Repeat rhythm R n times (e.g., Q.x6).
       Xm n    - Repeat m rhythms a total of n times.
       <ESC>   - Abandon Input or Correct a previous error.
```

Function Keys:

```text
       F1             - Get Help.
       F2..F8         - Enter normal rhythms shown on menu.
       <shift> F2..F8 - Enter dotted rhythms shown on menu.
       <Alt> F2..F8   - Enter triplet rhythms shown on menu.
```

```text
Alternate Keystrokes for windowing:   (Hold down <Alt> and press a key)
```

```text
       Alt C - CLOSE. Close graphics window to minimun size (Text window max.)
       Alt D - DOWN.  Move bottom of text window DOWN 1 line (make it bigger).
       Alt F - FULL.  Toggle FULL screen graphics on/off.
       Alt M - MENU.  Toggle function key MENU on/off.
       Alt O - OPEN.  Open graphics window to maximum size (Text window min.)
       Alt U - UP.    Move bottom of text window UP 1 line (make it smaller).
```

Keystrokes for text window and line editing:

```text
       Home      - Clear text window.
       Lft Arrow - Move text cursor left for line editing.
       Rht Arrow - Move text cursor right for line editing.
       Ins       - Toggle insert mode on/off for line editing.
       Del       - Delete character at current cursor location.
       BackSpace - Backup one space and delete character.
       Ctrl Q    - Regenerate last text line entered (must be first character).
```

Mouse:

```text
       Click Left button on menu   - Activate normal function key.
       Click Right button on menu  - Activate shifted function key (+dot).
       Click Middle button on menu - Activate alternate function key (triple).
       Click L,M or M,R buttons    - Abandon or Correct Input (same as ESC).
```
