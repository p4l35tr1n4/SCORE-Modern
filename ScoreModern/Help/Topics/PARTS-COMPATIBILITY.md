# PAGE extraction compatibility

Legacy PAGE and SCORLAS remain available through the original command workflow. Native PAGE results preserve the measured original cue and rest behaviour, including duplicated cue copies and the original loss of a rehearsal number inside a consolidated rest run. SCORE Modern Extension offers the separate preview-led Parts workflow with modern corrections.

Named DRAW and included EPS files in saved part-page packages can be reopened with their source identities intact. Keep the `.smxresources` index and referenced files beside the saved page, along with its page setup companion. Source resources are unchanged.

The shared engine adds explicit opt-in conventional pitch correction and composite-meter duration helpers. The available PAGE4 reference identifies as 4.00-540. The later 4.01 transposition correction has no identified trigger or distinct available reference binary; full corrected-PAGE4 equivalence is not certified.
