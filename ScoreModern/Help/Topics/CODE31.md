# Item Edit keys

## SCORE reference

> Source: Tom’s Help, edited by Thomas M. Brodhead.

The following keys are active in the Item Edit section of SCORE.

```text
Edit Mode Commands:
       <-  ->            - Move selected item left/right by one (1) unit.
       Up / Down Arrows  - Move selected item up/down by one (1) scale step.
       <TAB>             - Move selected item right ten (10) units.
       <shift><TAB>      - Move selected item left ten (10) units.
       PgUp / PgDn       - Move selected item up/down ten (10) scale steps.
       <Enter>           - Accept current item and select next item.
       F1 or ?           - Get Help.
       F2 or +/-         - Toggle editing direction forward / backward.
       F3 or <INS> or C  - Copy selected item.
       F4 or CN          - Center selected item over closest note(s).
       F5 or S           - Set: Select items near current position for Align.
       F6 or A           - Align selected item with Set position.
       F7 or <DEL> or DE - Delete selected item.
       F8                - Abort, and Undo any changes to selected item.
       F9-F10            - Move left or right ends of Code 4,5,6,7,8 items.
       <ESC> or <END>    - Exit Item Edit.
       <ALT>n            - Set param. number for editing with up/dn arrow keys.
       <HOME>            - Clear F9-F10 or <ALT>n.
       <numbers>         - Change item's parameters.  See Reference Manual.
```

```text
Alternate Keystrokes for windowing:   (Hold down <Alt> and press a key)
```

```text
Alt C - CLOSE. Close graphics window to minimun size (Text window max.)
Alt D - DOWN.  Move bottom of text window DOWN 1 line (make it bigger).
Alt F - FULL.  Toggle FULL screen graphics on/off.
Alt M - MENU.  Toggle function key MENU on/off.
Alt O - OPEN.  Open graphics window to maximum size (Text window min.)
Alt U - UP.    Move bottom of text window UP 1 line (make it smaller).
```

```text
Mouse:   (The mouse buttons are defined (L)eft, (M)iddle, and (R)ight below)
```

```text
Click L button on menu bar     - Activate normal function key.
Click L button on new position - Move item to new position.
Click R button on position     - Copy item to new position.
Click M button on new item     - Select new item for editing.
Click L,M or M,R together      - Exit Item Edit (same as ESC).
```

See SCORE Reference Manual and Manual Additions for other Edit Mode Commands.
