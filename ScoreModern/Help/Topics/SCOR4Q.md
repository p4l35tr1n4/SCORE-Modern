# Authoring legacy help · SCOR4

## In SCORE Modern Core

The 25-line instructions describe original DOS help authoring. This edition uses UTF-8 Markdown and scrollable topics in the help window.

## SCOR4 reference

> Source: Tom’s Help, edited by Thomas M. Brodhead.

FORMAT: Each page is 25 lines long and is terminated with an asterisk (*) in the first position.  Do NOT put an initial asterisk in lines indivisible by 25, lest the help screen parser misidentify the lines as page endings.

There are a maximum number of 20 pages; any more will overload the help screen parser in SCORE.

Let the final page end as you find page 2 here (view this text file in a pure ASCII editor to see the final two lines; the line beginning with the period should be the final line, and should be divisible by 25).
