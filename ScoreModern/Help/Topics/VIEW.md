# SCORE Modern · View, navigation, and compatibility

## Choose the notation view

Open **Preferences → Windows → Display & text** and choose the notation display:

- **High-resolution WYSIWYG** draws the print-oriented vectors.
- **DAT shapes at native resolution** uses SCORE’s screen glyph shapes at the Windows display resolution.
- **DAT shapes on a DOS-style pixel grid** shows the whole page using coarse pixels.
- **Original DOS viewport** uses the original framing and viewport rules. Use the DOS viewport zoom choices or the [Z commands](Z.md).

**Zoom framing** controls whether the zoom commands use DOS framing or a scrollable full page. **Page frame** in Workspace settings can follow the active print paper size or use Letter with overflow. Page padding and space around the drawn notation are separate settings.

## Set up the workspace

Use **Preferences → Windows → Workspace** to enable rulers, set their units, or adjust their colours and spacing. Use **Alt+D** to make more room for command text and **Ctrl+Alt+D** to give space back to the score. Use **Compact text** to reduce the space between text rows. Font family and explicit text size are separate choices.

When item hover markers are enabled, moving over the visible item shows its click-point and number. In Main mode both left and right clicks on the page can select an item. Right-click outside the page for Windows actions such as **PAGE…**, **DRAW…** or **Preferences…**.

## Select original operation

Enable **Strict SCORE behaviour** in **Preferences → Windows → SCORE compatibility** to use the available original rules for commands, selection and edits. Windows vectors and Type 1 rendering remain available with this preset. In the normal Windows configuration, the compatibility section offers individual choices. Consult item-specific help before changing packed numeric controls, especially when a compatibility switch controls their interpretation.

See [Strict SCORE behaviour](COMPAT.md) for the effect of each compatibility setting.
