# X commands · SCOR4

## SCOR4 reference

> Source: Tom’s Help, edited by Thomas M. Brodhead.

*Original fixed-width diagrams and examples retain their source spacing.*

"X" exits from edit mode. See E help. (?E)

"XX" exits from edit mode and copies the item to the !!CUT.TMP file.

The item may be retrieved at any later time by means of the paste command (PS).

Regarding CUT/PASTE see CT help. (?C)
